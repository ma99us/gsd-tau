# S03: Single-instance Lock, IPC Upgrade, Zustand Store — UAT

**Milestone:** M004
**Written:** 2026-07-21

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: All behaviors (single-instance lock, IPC handlers, Zustand store) are covered by the Vitest unit suite; no browser UI exists yet for these subsystems. The store drives tab bar rendering in S04, so browser-level validation is deferred to S04's UAT.

## Preconditions

- `pnpm install` completed
- No prior Electron instance running
- `pnpm test` exits 0

## Smoke Test

Run `pnpm test -- sessions-store` — all 45 store tests pass within 2 seconds.

## Test Cases

### 1. Single-instance lock arg parsing

1. Import `parseOpenProjectArg` from `main/ipc/handlers.ts`
2. Call with `['--open-project', '/some/path']`
3. **Expected:** Returns `'/some/path'`
4. Call with no flag
5. **Expected:** Returns `null`

### 2. Multi-session IPC: listSessions

1. Mock `SessionManager` with two open sessions
2. Call `listSessions()` IPC handler
3. **Expected:** Returns array of two `SessionRecord` objects with correct ids and cwds

### 3. Multi-session IPC: closeSession

1. Open a session, obtain its id
2. Call `closeSession(id)` IPC handler
3. **Expected:** Session teardown called; state machine cleaned up before `SessionManager.close()`

### 4. Zustand store: openTab / closeTab

1. Dispatch `openTab('/proj/a')`
2. Check `tabOrder` — contains new id; `activeTabId` set
3. Dispatch `closeTab(id)`
4. **Expected:** Tab removed from `sessions` and `tabOrder`; `activeTabId` updated to remaining tab or null

### 5. Zustand store: IPC sync

1. Mock `ipcRenderer.on` for `session:state-change`
2. Emit a synthetic state-change event
3. **Expected:** Store `sessions` map updated to reflect new state without full reset of actions

## Edge Cases

### Second instance with no --open-project

1. Second instance launched without `--open-project`
2. **Expected:** Second instance quits; first instance receives `second-instance` event but does not call `sessionManager.open()` (no-op)

### closeTab when it is the active tab

1. Two tabs open; close the active one
2. **Expected:** `activeTabId` moves to remaining tab, not null (when other tabs exist)

## Failure Signals

- Any test in `sessions-store.test.ts` or `handlers.test.ts` fails
- `pnpm exec tsc --noEmit` reports errors
- `parseOpenProjectArg` returns wrong value for edge-case argv arrays

## Not Proven By This UAT

- Actual Electron second-instance event firing end-to-end (requires packaged app)
- Tab bar rendering (deferred to S04)
- Restore flow after app reboot (deferred to S05)

## Notes for Tester

The Zustand store's `_resetStoreStateForTest` helper uses bare `setState` merge (no full-replace flag) — this is intentional to preserve actions during test resets.
