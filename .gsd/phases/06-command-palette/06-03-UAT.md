# S03: CommandPalette overlay component — UAT

**Milestone:** M006
**Written:** 2026-07-22

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: S03 proof level is "contract" — the slice ships a pure helper (filterAndSortCommands) and a React component. All roadmap proof points are covered by the vitest node-env test suite. No browser navigation or screenshot is required to validate the slice goal.

## Preconditions

- Node modules installed (`pnpm install`)
- S01 and S02 artifacts present (fuzzyScore, useMRU, useAppCommands)

## Smoke Test

Run `pnpm vitest run renderer/components/CommandPalette.test.ts` — all 20 tests must pass.

## Test Cases

### 1. Fuzzy filter returns compact-context first

1. Call `filterAndSortCommands('comp', appCommands, [])`
2. **Expected:** 'compact-context' is the first result (highest fuzzy score for 'comp').

### 2. MRU boost floats recently-used command above higher-scoring non-MRU

1. Call `filterAndSortCommands('o', appCommands, ['open-project'])` where 'open-project' is in MRU
2. **Expected:** 'open-project' ranks above any higher-scoring non-MRU command.

### 3. Empty query returns MRU-sorted list

1. Call `filterAndSortCommands('', appCommands, ['compact-context', 'new-session'])`
2. **Expected:** 'compact-context' first, 'new-session' second, remaining commands follow in registry order.

## Edge Cases

### Empty command list

1. Call `filterAndSortCommands('comp', [], [])`
2. **Expected:** Returns empty array, no error.

### Query with no matches

1. Call `filterAndSortCommands('zzz', appCommands, [])`
2. **Expected:** Returns empty array.

## Failure Signals

- Any test failure in `CommandPalette.test.ts` indicates a regression in fuzzy scoring, MRU logic, or the exported helper API.

## Not Proven By This UAT

- Radix Dialog focus trap and overlay rendering — deferred to S04 manual verification
- Pi slash commands appearing in palette — deferred to S05
