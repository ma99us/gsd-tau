# S04: Context window gauge with compact button

**Goal:** Add a live context-window gauge to the session header that shows token fill percentage with colour coding (green/amber/red), a click-to-open popover with input/output/cache breakdown, and a Compact button that calls the pi compact() RPC. Wire a new COMPACT IPC channel end-to-end (session-manager → handlers → preload → renderer).
**Demo:** Header shows 'Context ██████░░░░ 62%'. Click gauge; popover shows input/output/cache breakdown and Compact button. At 85%+ gauge turns red.

## Must-Haves

- `ContextGauge` renders in SessionHeaderBar with live token percentage from cost_update events
- Colour transitions: green below 60%, amber 60-85%, red at 85%+
- Unknown contextWindow falls back to raw "Context Nk tokens" display (no bar)
- Popover shows input/output/cacheRead/cacheWrite/total breakdown
- Compact button calls window.gsd.compact(sessionId) and shows loading state during round-trip
- COMPACT IPC channel registered end-to-end with null-on-error pattern
- pnpm tsc --noEmit passes; pnpm test passes

## Proof Level

- This slice proves: automated — tsc type check + unit tests (colour logic, fallback, compact delegation) + pnpm test suite

## Integration Closure

ContextGauge subscribes to cost_update events via window.gsd.onEvent and reads stats.tokens directly from the event payload (no extra getSessionStats round-trip). compact() round-trip goes renderer → preload → handlers → session-manager → RpcClient.compact(). SessionHeaderBar passes modelInfo.contextWindow into ContextGauge.

## Verification

- COMPACT handler logs errors through existing try/catch→null pattern consistent with other IPC handlers. isCompacting flag in ContextGauge prevents duplicate in-flight compact calls.
