# S01: Session header: model chip and cost line

**Goal:** Add a SessionHeaderBar component to every open session that shows the active model identifier and live cumulative cost, sourced via two new IPC channels (GET_RPC_STATE, GET_SESSION_STATS) wired through the established pattern: session-manager → handlers → preload → renderer hook.
**Demo:** Open a project; header shows 'anthropic/claude-sonnet-4.6  $0.00'. Send a message; cost updates after execution_complete.

## Must-Haves

- Open a project; header row shows provider/model-id  $0.00. Send a message; cost ticks up during streaming and settles after execution_complete. TypeScript clean, all existing tests passing.

## Integration Closure

SessionHeaderBar is wired into SessionView above TurnList. Two new IPC channels exposed end-to-end. cost_update events flow from pi → main → renderer without additional wiring in later slices.
