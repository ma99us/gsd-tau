# S03: Thinking level chip and picker

**Goal:** Wire `set_thinking_level` from RPC through to the renderer: add IPC channel + session-handle method + preload binding, then render a `ThinkingLevelChip` in `SessionHeaderBar` that shows the current thinking level (hidden on non-reasoning models), lets the user pick from all 7 levels optimistically, and supports `Ctrl+Shift+T` cycling.
**Demo:** Header shows '💡 medium'. Click chip; picker shows all 7 levels with current selected. Pick 'high'; chip updates to '💡 high'. On a non-reasoning model chip is absent.
