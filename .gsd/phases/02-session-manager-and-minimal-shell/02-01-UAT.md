# S01: Project Scaffold and Tooling — UAT

**Milestone:** M002
**Written:** 2026-07-20

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: S01 delivers a build scaffold and a pure-logic resolver (no browser UI). All acceptance criteria are verifiable by running build and test commands; no localhost/browser interaction is required.

## Preconditions

- Node.js and pnpm installed and on PATH
- Electron binary present (run `node node_modules/electron/install.js` if absent)
- Working directory: `D:/Projects/gsd-tau`
- pnpm install completed (with `--ignore-scripts` on pnpm v11)

## Smoke Test

Run `pnpm test` — vitest exits 0 with all 4 resolve-pi cases green.

## Test Cases

### 1. Build pipeline compiles without errors

1. Run `pnpm build`
2. **Expected:** electron-vite exits 0; out/main/index.js, out/preload/preload.js, and out/renderer/index.html are emitted; no TypeScript errors.

### 2. Lint passes with zero warnings

1. Run `pnpm lint`
2. **Expected:** eslint exits 0 with no output (zero errors, zero warnings).

### 3. resolvePiBinary() — PATH resolution

1. Ensure `gsd` is on PATH (default machine state)
2. Run `pnpm test -- resolve-pi`
3. **Expected:** "PATH hit" test case passes; returned path is a non-empty string.

### 4. resolvePiBinary() — GSD_PI_PATH override

1. Set `GSD_PI_PATH` env var to a valid path
2. Run `pnpm test -- resolve-pi`
3. **Expected:** "env var override" test case passes; resolvePiBinary() returns the env-specified path.

### 5. resolvePiBinary() — not-found error

1. Run `pnpm test -- resolve-pi` in a context where PATH has no `gsd` and no common locations match
2. **Expected:** "not-found error" test case passes; ResolvePiError is thrown with an actionable message.

## Edge Cases

### Empty GSD_PI_PATH treated as unset

1. Set `GSD_PI_PATH=""` (empty string)
2. Run the resolver
3. **Expected:** Falls through to PATH search; empty string is not validated as a path.

### Malformed env var path

1. Set `GSD_PI_PATH` to a non-existent path
2. Run the resolver
3. **Expected:** ResolvePiError thrown with message referencing the bad path.

## Failure Signals

- Any vitest failure in resolve-pi suite
- pnpm build emitting TypeScript errors or non-zero exit
- pnpm lint reporting errors or warnings

## Not Proven By This UAT

- `pnpm dev` launching a visible Electron window (requires display/Electron binary + GUI environment)
- Playwright smoke suite (deferred to S06)
- Actual runtime resolution on a machine without gsd installed

## Notes for Tester

pnpm v11 requires `--ignore-scripts` on install; run `node node_modules/electron/install.js` separately to download the Electron binary (~100MB). The test suite mocks fs and child_process so no real gsd binary is needed to run vitest.
