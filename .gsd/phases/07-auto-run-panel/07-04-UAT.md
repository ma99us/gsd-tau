**Milestone:** M007
**Written:** 2026-07-22

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: All integration points (IPC subscription, toggle, Pause/Refresh/OpenRoadmap) are covered by unit tests in vitest. The running-app flow requires a live pi auto session; runtime-executable via `pnpm vitest run` confirms the wiring contracts. The Playwright smoke suite confirms the Electron app shell.

## Preconditions

- `pnpm install` completed
- `pnpm tsc --noEmit` exits 0
- Dev server not required — unit tests are self-contained

## Smoke Test

Run `pnpm vitest run` and confirm 1177 tests pass across 42 test files.

## Test Cases

### 1. TypeScript compilation clean

1. Run `pnpm tsc --noEmit`
2. **Expected:** Exit 0, no diagnostics. All S04 files (shared/types.ts, preload/preload.ts, main/ipc/handlers.ts, renderer/components/SessionView.tsx, and their test files) compile without errors.

### 2. Full vitest suite

1. Run `pnpm vitest run`
2. **Expected:** 42 test files, ≥1177 tests, all passed. Zero failures.

### 3. IPC handler count

1. Run `pnpm vitest run --reporter=verbose 2>&1 | grep "ipcMain.handle"` or inspect handlers.test.ts output
2. **Expected:** Registration assertion for 26 handlers passes (openRoadmap added in T01).

### 4. AutoRunPanel visibility gate (unit)

1. In SessionView.test.ts, the visibility gate test exercises: progress=null → panel hidden; progress with milestone → panel shown when panelOpen=true; panel hidden when panelOpen=false.
2. **Expected:** All three visibility assertions pass in vitest.

### 5. Ctrl+Slash toggle (unit)

1. SessionView.test.ts dispatches a keydown event with key='/' and ctrlKey=true on an active session.
2. **Expected:** panelOpen toggles; test passes in vitest.

## Edge Cases

### openRoadmap with unknown milestoneId

1. Handler receives sessionId whose session has no active milestone.
2. **Expected:** console.warn logged; shell.openPath not called; no crash.

### openRoadmap with milestone directory not found

1. Handler resolves numeric prefix but no matching directory exists in .gsd/phases.
2. **Expected:** console.warn logged; shell.openPath not called.

## Failure Signals

- TSC non-zero exit or vitest failures indicate a regression in S04 wiring
- "ipcMain.handle count" assertion failure means openRoadmap was not registered
- AutoRunPanel visibility tests failing means SessionView conditional render broke

## Not Proven By This UAT

- Live app: actual panel appearing in Electron window during a real `/gsd auto` session
- OS file open: shell.openPath actually launching the default editor (requires live Electron)
- Ctrl+Slash in the actual running app window (keyboard event simulation is unit-only)
- Path B reconciliation triggering on Refresh click in the live app

The `handleOpenRoadmap` callback in SessionView is fully implemented but AutoRunPanel has no `onOpenRoadmap` prop yet (noted in T02 deviations). The button will appear in a follow-up slice/task that adds the prop to AutoRunPanel without requiring SessionView changes.
