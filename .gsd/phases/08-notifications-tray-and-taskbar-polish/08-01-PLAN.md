# S01: Expand toast coverage to Stopped and milestone complete

**Goal:** Add showStoppedToast and showMilestoneCompleteToast to the notifications module, wire both into handlers via the MEM016 injectable-callback pattern, emit a dedicated 'milestone-complete' event from ProgressTracker, and pass real implementations from main/index.ts.
**Demo:** Session crashes → Stopped toast appears. gsd_complete_milestone tool fires → milestone-complete toast appears. Blocker toast still works.

## Must-Haves

- showStoppedToast fires when session state transitions to Stopped
- showMilestoneCompleteToast fires when gsd_complete_milestone tool event is processed
- Neither toast fires for unrelated state/progress events
- Existing showBlockerToast behaviour unchanged
- All 1184+ existing tests still pass; new unit tests cover both new toast paths

## Proof Level

- This slice proves: integration

## Integration Closure

Real OS notifications wired through index.ts. ProgressTracker emits 'milestone-complete'. Handlers subscribe and call toast functions. No new libraries needed.
