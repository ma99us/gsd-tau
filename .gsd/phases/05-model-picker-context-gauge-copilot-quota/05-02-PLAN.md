# S02: Model picker dropdown

**Goal:** Add a clickable model picker dropdown to the model chip in SessionHeaderBar. Clicking the chip opens a grouped list of available models from get_available_models. Picking a model calls set_model, updates the chip optimistically, and confirms on the next getRpcState fetch.
**Demo:** Click 'anthropic/claude-sonnet-4.6'; dropdown shows all available models grouped by provider. Pick a different model; chip updates immediately.

## Must-Haves

- Click the model chip; dropdown opens showing all models grouped by provider with contextWindow and reasoning badge metadata. Pick a different model; chip updates immediately (optimistic). Next execution_complete confirms via GET_RPC_STATE.
