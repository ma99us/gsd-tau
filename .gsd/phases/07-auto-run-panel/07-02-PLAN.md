# S02: SessionHandle integration and Path B reconciliation

**Goal:** Wire ProgressTracker into the live session pipeline and expose GsdProgress over IPC so the renderer can subscribe to real-time auto-run updates.
**Demo:** In the running app with a live auto session: open DevTools, start /gsd auto, observe window.gsd.onProgressUpdate callbacks firing; after execution_complete the reconciliation runs and the snapshot matches gsd_milestone_status output.

## Must-Haves

- `cost_update` events reach ProgressTracker (not silently dropped via unknown-event channel)
- ProgressTracker is instantiated per session in doOpenProject() and cleaned up on session close
- `window.gsd.onProgressUpdate(sessionId, cb)` fires in the renderer whenever ProgressTracker emits 'updated'
- `window.gsd.getProgress(sessionId)` returns the current GsdProgress snapshot
- Path B reconciler fires on `execution_complete` and corrects drift against ROADMAP.md checkboxes
- `pnpm tsc --noEmit` exits 0; `pnpm vitest run` passes all tests
