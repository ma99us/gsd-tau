# S06: Reboot Test Fix, activeTabId Restore, and UAT Completion — UAT

**Milestone:** M004
**Written:** 2026-07-21

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: The core deliverable (activeTabCwd persistence and restore) is exercised by the Playwright reboot-cycle spec and the Vitest unit suite. Both can be invoked as commands without a running dev server for the unit layer; the Playwright test drives the full Electron app.

## Preconditions

- Node dependencies installed (`pnpm install`)
- Electron app builds correctly (no tsc errors)
- Playwright test fixtures (project-a/b/c temp dirs) are created by the spec itself

## Smoke Test

Run `pnpm exec vitest run renderer/state/sessions-store.test.ts` — must report 51 passed, 0 failed.

## Test Cases

### 1. sessions-store unit suite passes completely

1. Run `pnpm exec vitest run renderer/state/sessions-store.test.ts`
2. **Expected:** 51 passed, 0 failed. All `init()` tests pass (listMissingPaths and onSessionMissingPath stubs present in mock).

### 2. TypeScript compiles with no errors

1. Run `pnpm exec tsc --noEmit`
2. **Expected:** Exit 0, no diagnostic output. All 7 modified files type-check cleanly.

### 3. Full unit suite — no new failures

1. Run `pnpm exec vitest run`
2. **Expected:** 601+ passed. Any failures are only in `main/session/session-manager.test.ts` (pre-existing, unrelated to this slice).

### 4. Playwright reboot-cycle: exact active-tab assertion

1. Run `pnpm exec playwright test test/reboot-cycle.spec.ts` (requires built Electron app)
2. Open 3 project tabs; activate project-c last; quit and relaunch.
3. **Expected:** After restore, the active tab label contains `project-c`. Assertion `expect(activeLabel).toContain('project-c')` passes.

### 5. activeTabCwd persists on tab switch

1. Launch app, open three sessions.
2. Click the project-c tab.
3. Inspect `%APPDATA%\gsd-tau\registry.json`.
4. **Expected:** The window record's `activeTabCwd` field equals the project-c directory path.

## Edge Cases

### Quick tab-switch-then-quit

1. Rapidly switch tabs and immediately quit the app.
2. Relaunch.
3. **Expected:** The last tab that was active before quit is restored as active (synchronous in-memory mutation in `updateWindowActiveTab` prevents stale CWD on fast quit).

### Missing-path banner after relaunch with deleted project

1. Open a session for a directory, delete that directory, relaunch.
2. **Expected:** Missing-path banner appears for the deleted project session.

## Failure Signals

- `sessions-store.test.ts` reports failures → mock is stale or store logic regressed
- `tsc --noEmit` reports errors → type contract broken in one of the 7 modified files
- Playwright active-tab assertion fails → activeTabCwd not persisted or not restored correctly
- `activeTabCwd` absent from registry.json after tab switch → `saveWindowActiveTab` IPC not firing

## Not Proven By This UAT

- Live Playwright run against a packaged NSIS installer
- Multi-window (detached) activeTabCwd persistence (deferred to a future slice)
- Copilot auth and provider flows (out of scope for M004)

## Notes for Tester

The 6 pre-existing failures in `main/session/session-manager.test.ts` are expected and unrelated to this slice. The Playwright reboot-cycle test requires the full Electron build; unit tests do not.
