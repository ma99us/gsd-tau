**Milestone:** M003
**Written:** 2026-07-20

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: All acceptance criteria are verified by the Playwright e2e suite (`pnpm test:e2e`) and a tsc type-check. No interactive browser navigation beyond what Playwright automates is needed.

## Preconditions

- Node dependencies installed: `pnpm install`
- App compiled: `pnpm build` (produces `out/main/index.js`)
- Playwright Chromium available (installed via pnpm postinstall)

## Smoke Test

Run `pnpm build && pnpm test:e2e` — expect exit 0 and "8 passed" in the summary line.

## Test Cases

### 1. TypeScript clean compile

1. Run `pnpm exec tsc --noEmit`
2. **Expected:** Exit 0, no TypeScript diagnostics emitted.

### 2. Full Playwright e2e suite — 8/8 pass

1. Run `pnpm build` (exit 0, `out/main/index.js` produced)
2. Run `pnpm test:e2e`
3. **Expected:** Exit 0, output includes "8 passed" within ~20s, `test-results/` contains only `.last-run.json` (no failure screenshots or traces).

### 3. UI-request tests respond with defined values (tests 1–7)

1. After `pnpm test:e2e`, inspect output for tests named `ui-request (1)` through `ui-request (7)`
2. **Expected:** All 7 pass — no "undefined" response values, no timeout failures.

### 4. CI workflow structural validity

1. Read `.github/workflows/ci.yml`
2. **Expected:** Four jobs declared: `lint`, `test`, `build`, `e2e`. `e2e` job has `needs: [build]`. Both `build` and `e2e` jobs reference `actions/upload-artifact` and `actions/download-artifact` respectively. All jobs use `windows-latest` and `shell: pwsh`.

## Edge Cases

### Cleanup before assertion (regression guard)

1. Inspect `test/ui-requests.spec.ts` — confirm `cleanTmpDir(tmpDir)` calls appear **after** `expect(...)` assertions, not inside `finally` blocks for tests 1–6.
2. **Expected:** No `cleanTmpDir` calls inside `finally` blocks for the six fixed tests.

## Failure Signals

- Any test shows "undefined" as a response value → cleanup-ordering regression
- `tsc --noEmit` reports errors → type regression in test or source files
- e2e job in CI fails to find `out/main/index.js` → artifact upload/download misconfiguration

## Not Proven By This UAT

- Windows toast 500ms SLA under real OS conditions (not exercised by Playwright)
- CI pipeline actually running on GitHub (requires a push/PR to GitHub)
- Playwright tests on macOS/Linux (out of scope — Windows-only project)

## Notes for Tester

The suite runs 8 tests: 7 ui-request interaction tests plus 1 smoke test. "8 passed" is correct and expected — not 7. The file `test-results/.last-run.json` is normal Playwright metadata and does not indicate a failure.
