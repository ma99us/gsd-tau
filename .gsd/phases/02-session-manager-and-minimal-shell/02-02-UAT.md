# S02: pi Client and Event Pump — UAT

**Milestone:** M002
**Written:** 2026-07-20

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: S02 has no renderer or browser surface — it is a pure Node/main-process layer (factory + event pump). All acceptance criteria are fully covered by the Vitest suite which exercises the RPC contract against mocked client internals. No live pi process or Electron window is required at this slice boundary.

## Preconditions

- `pnpm install` completed (node_modules present)
- Vitest available via `pnpm test`
- No live pi process required (all tests use mocked RpcClient)

## Smoke Test

Run `pnpm test -- client-factory session-handle` — both test files must pass (41 tests).

## Test Cases

### 1. createClient() orders start() before init()

1. Run `pnpm test -- client-factory`
2. **Expected:** test "calls start() then init() in order" passes; MockRpcClient records start before init.

### 2. createClient() throws ClientInitError on protocol v1

1. Run `pnpm test -- client-factory`
2. **Expected:** test "throws ClientInitError if protocolVersion is not 2" passes; error message mentions "requires v2".

### 3. createClient() throws ClientInitError on init failure

1. Run `pnpm test -- client-factory`
2. **Expected:** tests for ECONNRESET and timeout paths pass; `ClientInitError` carries `piPath`.

### 4. SessionHandle event pump dispatches all known event types

1. Run `pnpm test -- session-handle`
2. **Expected:** it.each test covering agent_start, agent_end, message, text_delta, tool_use, tool_result all pass.

### 5. SessionHandle transport-error suppressed after stop()

1. Run `pnpm test -- session-handle`
2. **Expected:** "does not emit transport-error after stop()" test passes.

### 6. text_delta leading-edge throttle collapses bursts

1. Run `pnpm test -- session-handle`
2. **Expected:** throttle tests pass — first delta emitted immediately, burst collapses to latest, trailing flush on pump end.

## Edge Cases

### stop() before start()

1. Run `pnpm test -- session-handle`
2. **Expected:** "stop before start is safe" test passes; no crash, state is stopped.

### Binary resolution priority

1. Run `pnpm test -- client-factory`
2. **Expected:** "uses opts.binary when provided" test passes; resolvePiBinary() not called.

## Failure Signals

- Any test failure in `client-factory` or `session-handle` suites
- `ClientInitError` not thrown when init returns protocolVersion 1
- transport-error emitted after stop() (suppression broken)

## Not Proven By This UAT

- Live pi process integration (real `gsd --mode rpc` child)
- Actual IPC fan-out to renderer (S04)
- Electron window or browser surface (S05+)

## Notes for Tester

All tests use a mocked RpcClient — no live gsd binary is exercised. Live integration is deferred to S03/S04 where the SessionManager wires the factory into the main process and IPC bridge is tested end-to-end.
