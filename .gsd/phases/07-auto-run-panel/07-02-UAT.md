## Edge Cases

### Reconciler called with no milestone ID

1. Trigger `execution_complete` on a session with no active milestone
2. **Expected:** `console.warn` fires ("no milestone ID"); reconciliation is skipped; no error thrown; session continues normally

### ROADMAP.md file missing

1. `reconcileProgress` called with a path that does not exist

## Notes for Tester

The reconcileProgress path uses `{cwd}/.gsd/phases/{milestoneId}/{milestoneId}-ROADMAP.md`. In gsd-tau's own dev environment the directory names use numeric prefixes (`07-auto-run-panel`), so self-hosted runs will emit a console.warn for missing ROADMAP and skip reconciliation — this is expected and correct behaviour for the dev environment. User projects driven by pi auto-mode will have the correct path layout.
