# S03: Session State Machine and Manager — UAT

**Milestone:** M002
**Written:** 2026-07-20

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: S03 delivers pure TypeScript logic (no renderer, no Electron window, no localhost server). All acceptance criteria are fully covered by the Vitest suite — running `pnpm test -- state-machine` and `pnpm test -- session-manager` is objective, repeatable, and produces structured pass/fail evidence. No browser interaction is needed or possible at this stage.

## Preconditions

- Node 20+ and pnpm installed.
- `pnpm install` has been run (node_modules present).
- `main/session/state-machine.ts` and `main/session/session-manager.ts` exist.

## Smoke Test

Run `pnpm test -- state-machine` — all 25 tests pass with exit 0.

## Test Cases

### 1. State machine: all valid transitions

1. Run `pnpm test -- state-machine`
2. **Expected:** 1 test file, 25 tests passed, 0 failed, exit 0.

### 2. State machine: watchdog timeout

1. Within the Vitest suite (configurable `watchdogMs`), a Working session with no activity for the watchdog interval fires `watchdog-timeout` and transitions to Stopped.
2. **Expected:** Watchdog test cases pass (covered in the 25-test suite).

### 3. SessionManager: open / get / close lifecycle

1. Run `pnpm test -- session-manager`
2. **Expected:** 1 test file, 29 tests passed, 0 failed, exit 0.

### 4. SessionManager: Phase-1 single-session guard

1. Within the suite, calling `open()` while a session is active throws.
2. **Expected:** Guard test cases pass (covered in the 29-test suite).

### 5. SessionManager: shutdown timeout fallback

1. Within the suite, if `client.shutdown()` does not resolve within 3s, `client.stop()` is called as a fallback.
2. **Expected:** Timeout test cases pass (covered in the 29-test suite).

## Edge Cases

### Stopped is terminal

1. Transition to Stopped (via transport-error or watchdog-timeout).
2. Attempt `agent_start`.
3. **Expected:** Transition is a no-op; state remains Stopped.

### Double-close prevention

1. `close(id)` is called on an already-closed session.
2. **Expected:** No crash, no double teardown; session was removed from Map before async teardown begins.

## Failure Signals

- Any test exits non-zero or reports failed tests.
- `pnpm test -- state-machine` or `pnpm test -- session-manager` throws an error.

## Not Proven By This UAT

- Integration with live pi process (deferred to S04+).
- IPC bridge exposure of SessionManager (S04).
- Multi-session support (deferred to a later phase).
- Runtime behavior inside a running Electron app.

## Notes for Tester

Tests use mocked `createClient` — no pi binary is required. `watchdogMs` is configurable so the watchdog tests run in milliseconds, not 30 seconds. No Electron window or dev server is needed for this slice.
