## Operational Readiness
- **Health signal:** When a session opens and STATE.md contains an active milestone, the debug log line `[handlers] open-time Path B: reconciled N slice(s) for milestone MMM (session <id>)` is emitted. Absence of this line for a known auto-mode project indicates the seeding block was skipped or STATE.md was not found.
- **Failure signal:** If `reconcileProgress` throws or STATE.md is unreadable, errors are swallowed silently (by design — new projects have no STATE.md). No alert is raised; this is intentional graceful degradation. A future improvement could surface a "Progress may be stale" hint if reconciliation was expected but skipped.
- **Recovery:** If seeding does not fire (new project, missing STATE.md, or I/O error), the panel starts empty and Path B will seed on the next `execution_complete` event or 60s cadence. No manual recovery needed.
- **Monitoring gap:** Silent error swallowing means a persistent reconciliation failure (e.g. malformed STATE.md) is not surfaced to the user. Mitigated by the 60s cadence Path B fallback.
