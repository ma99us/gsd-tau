# S05: Copilot quota service and header widget

**Goal:** Ship the Copilot quota service (main-process singleton) and a compact header widget (renderer) that shows live GitHub Copilot usage, polls every 15 min, and degrades gracefully when unauthenticated or offline.
**Demo:** Header shows 'Copilot ████████░░ 78%  ✅'. Click widget; popover shows used/remaining/reset date, burn rates, projection, and last-updated time. Without auth shows Connect GitHub button.

## Must-Haves

- Header shows "Copilot ████████░░ 78% ✅" when authenticated and data is available. Click widget opens popover with used/remaining/reset date, burn rates, and last-updated time. Without auth shows "Connect GitHub" button. Service polls every 15 min, fetches on startup (if token present), and on demand. Stale/offline state shows last known values with stale indicator. pnpm tsc --noEmit exits 0; pnpm test passes (≥614 tests).

- This slice proves: unit + manual smoke
