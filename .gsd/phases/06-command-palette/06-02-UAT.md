# S02: App command registry — UAT

**Milestone:** M006
**Written:** 2026-07-22

## UAT Type

- UAT mode: artifact-driven
- Why this mode is sufficient: S02 delivers a pure hook/factory with no UI and no runtime server requirement. All correctness is verified by the 34-test vitest suite.

## Preconditions

- `pnpm install` completed in `D:/Projects/gsd-tau`
- No dev server required

## Smoke Test

Run `pnpm vitest run renderer/hooks/useAppCommands.test.ts` — expect `34 passed`.

## Test Cases

### 1. All 7 command IDs present

1. Call `buildAppCommands('session-1')`
2. Extract `ids = result.map(c => c.id)`
3. **Expected:** ids contains exactly: `new-session`, `open-project`, `close-tab`, `compact-context`, `copy-last-turn`, `show-tray`, `toggle-auto-run-panel`

### 2. Null sessionId no-ops for session-scoped commands

1. Call `buildAppCommands(null)`
2. Invoke `close-tab.execute()` and `compact-context.execute()`
3. **Expected:** No IPC calls made; no error thrown

### 3. copy-last-turn delegates to injected callback

1. Call `buildAppCommands('s1', () => 'last text')`
2. Invoke `copy-last-turn.execute()`
3. **Expected:** `navigator.clipboard.writeText` called with `'last text'`

### 4. show-tray and toggle-auto-run-panel emit console.warn stubs

1. Call `buildAppCommands('s1')`
2. Invoke `show-tray.execute()` and `toggle-auto-run-panel.execute()`
3. **Expected:** `console.warn` called with a not-yet-wired message; no IPC call made

## Edge Cases

### getLastTurnText not provided

1. Call `buildAppCommands('s1')` (no second arg)
2. Invoke `copy-last-turn.execute()`
3. **Expected:** clipboard write called with empty string or no-op — no crash

## Failure Signals

- Any test in `useAppCommands.test.ts` failing
- Missing command IDs in the returned array
- IPC calls emitted from show-tray/toggle-auto-run-panel (phantom IPC)

## Not Proven By This UAT

- Runtime IPC integration with `window.gsd.*` (proven in S04 keyboard wiring)
- UI rendering of commands in the palette (proven in S03)
- MRU ordering (proven in S01/S03)

## Notes for Tester

All 34 tests are pure unit tests — no browser, no Electron, no dev server required. The stubs for show-tray and toggle-auto-run-panel are intentional; they will be wired in S04.
