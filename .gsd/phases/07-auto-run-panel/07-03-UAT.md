# S03: AutoRunPanel React component — UAT

**Milestone:** M007
**Written:** 2026-07-22

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: AutoRunPanel is a pure presentation component with no runtime side effects and no browser interactions. All observable behaviour is captured by the Node vitest suite; no dev server is required.

## Preconditions

- `pnpm install` has been run.
- Node vitest is available (`pnpm vitest`).

## Smoke Test

Run `pnpm vitest run renderer/components/AutoRunPanel.test.ts` — expect 34/34 tests pass, exit 0.

## Test Cases

### 1. Pure helper: statusIcon returns correct icon strings

1. Import `statusIcon` from `AutoRunPanel.tsx`.
2. Call with each GsdNodeStatus value: `complete`, `in_progress`, `pending`, `skipped`.
3. **Expected:** Returns the correct Unicode icon for each status; TypeScript exhaustiveness guard fires at compile time for unknown values.

### 2. Pure helper: formatCost formats dollar values

1. Call `formatCost(0)`, `formatCost(0.005)`, `formatCost(1.5)`.
2. **Expected:** `"$0.00"`, `"$0.01"` (round-up), `"$1.50"`.

### 3. Pure helper: formatElapsed formats durations

1. Call `formatElapsed(0, 30000)` (30 s), `formatElapsed(0, 90000)` (90 s), `formatElapsed(0, 3700000)` (>1 h).
2. **Expected:** `"30s"`, `"1m 30s"`, `"1h 1m"`.

### 4. Pure helper: computePanelFooter aggregates cost and elapsed

1. Build a GsdProgress fixture with known costs on tasks.
2. Call `computePanelFooter(progress, nowMs)`.
3. **Expected:** Returns summed cost and elapsed from startedAt to nowMs.

### 5. Component: null milestone renders gracefully

1. Render `<AutoRunPanel progress={{ milestone: null }} onPause={…} onRefresh={…} />` (via vitest).
2. **Expected:** No throw; renders empty or placeholder state.

### 6. Component: Pause and Refresh callbacks

1. Render panel with fixture GsdProgress; click Pause and Refresh buttons.
2. **Expected:** `onPause()` and `onRefresh()` are called exactly once each.

## Edge Cases

### Replan marker visibility

1. Build a fixture slice with `replanCount > 0`.
2. Render panel.
3. **Expected:** Replan marker is visible on that slice row.

### Skipped slice

1. Build a fixture slice with status `skipped`.
2. Render panel.
3. **Expected:** statusIcon returns the skip icon; row renders without error.

## Failure Signals

- Any vitest test failure with non-zero exit code.
- TypeScript error from `pnpm tsc --noEmit`.
- Missing export error when S04 imports `statusIcon`, `formatCost`, `formatElapsed`, `computePanelFooter` from `AutoRunPanel.tsx`.

## Not Proven By This UAT

- Live rendering in the Electron renderer process.
- Visual pixel-level appearance (colours, spacing, scroll behaviour).
- Integration with live GsdProgress updates from the IPC bridge (proven in S04).

## Notes for Tester

All tests are deterministic — no Date.now() mocking needed due to explicit nowMs parameter injection. The 0.006 cost boundary value in the formatCost test intentionally avoids floating-point ambiguity at the 0.005 boundary.
