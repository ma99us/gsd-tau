# UAT: S05 — Copilot Quota Service and Header Widget

## UAT Type
- UAT mode: runtime-executable

## Preconditions
- Dev server running: `pnpm dev` → Electron app at working state
- All 859 unit tests passing (`pnpm test --run`)
- `pnpm tsc --noEmit` exits 0
- For authenticated path: `GSD_TAU_GITHUB_CLIENT_ID` env var set and valid `gh-auth.json` present in `%APPDATA%/gsd-tau/`
- For unauthenticated path: no `gh-auth.json` present

## Test Cases

### UAT-01: Unauthenticated state — Connect GitHub button
**Steps:**
1. Launch app with no `gh-auth.json` present
2. Open any project session
3. Observe SessionHeaderBar

**Expected:** QuotaWidget renders "Connect GitHub" button (no progress bar). No error thrown.

### UAT-02: Authenticated state — progress bar in header
**Steps:**
1. Launch app with valid `gh-auth.json`
2. Open any project session
3. Observe SessionHeaderBar

**Expected:** Header shows `Copilot ████████░░ 78% ✅` (bar fill reflects `percentRemaining`; emoji reflects verdict).

### UAT-03: Popover — used/remaining/reset date/burn rates/projection
**Steps:**
1. With valid auth, click the QuotaWidget in the header

**Expected:** Popover opens showing: used count, remaining count, reset date, daily/weekly burn rates, projected depletion date, last-updated timestamp. All values non-zero.

### UAT-04: Stale/offline degradation
**Steps:**
1. Disconnect network
2. Wait for next 15-min poll (or call `window.gsd.refreshQuota()` in DevTools)

**Expected:** Widget shows last known values with stale indicator. No crash. `[quota-service]` log line visible in main-process log on fetch error.

### UAT-05: IPC channels reachable from renderer DevTools
**Steps:**
1. Open Electron DevTools → Console
2. Run `await window.gsd.getQuota()`

**Expected:** Returns a `QuotaSnapshot` object (or `null` if unauthenticated). No unhandled promise rejection.

### UAT-06: Unit test suite passes
**Steps:**
1. Run `pnpm test --run`

**Expected:** 859 tests pass, 0 failures across 33 test files.

## Edge Cases
- No `gh-auth.json`: widget shows Connect GitHub, no API call made
- API returns 401: verdict set to `unauthenticated`, widget degrades gracefully
- API returns 5xx: last known snapshot retained, stale indicator shown
- `GSD_TAU_GITHUB_CLIENT_ID` not set: `startQuotaAuth` rejects with clear error logged; no crash

## Automation Notes
UAT-06 is fully automated via `pnpm test --run`. UAT-01 through UAT-05 require the Electron app running with controlled auth state; they are manual smoke tests until a Playwright fixture with mock IPC is available.
