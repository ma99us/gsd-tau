# S04: Tab Bar and Open Project Flyout — UAT

**Milestone:** M004
**Written:** 2026-07-21T15:03:35.310Z

## UAT Type
- UAT mode: runtime-executable

## Preconditions
1. `pnpm install` completed.
2. `pnpm run dev` (or equivalent Vite dev server) running at `http://localhost:5173` with Electron window open.
3. At least two folders exist that can serve as "projects" (e.g. `test/fixtures/project-a` and `test/fixtures/project-b`).

## Test Cases

### TC-1: Tab Bar renders with state dot
1. Open a session from the landing screen.
2. Observe the tab bar: the tab shows the project display name (≤24 chars) and a coloured dot.
3. **Expected:** dot is green (Idle) at rest; turns yellow/pulsing when a pi turn is in progress.

### TC-2: Drag to reorder tabs
1. Open two sessions (project-a, project-b).
2. Drag the second tab to the left of the first.
3. **Expected:** tab order reverses; active tab selection is preserved.

### TC-3: Right-click context menu
1. Right-click any tab.
2. **Expected:** context menu appears with "Rename" and "Close" items.
3. Click "Rename"; type a new name; press Enter.
4. **Expected:** tab label updates.

### TC-4: Middle-click closes idle tab
1. Open a session in Idle state.
2. Middle-click the tab.
3. **Expected:** tab closes without a confirmation dialog.

### TC-5: Keyboard shortcuts
1. Press Ctrl+T — **Expected:** Open Project flyout opens.
2. Press Escape — **Expected:** flyout closes.
3. With two tabs open, press Ctrl+Tab — **Expected:** focus shifts to next tab.
4. Press Ctrl+W — **Expected:** active tab closes.

### TC-6: Open Project flyout — recents
1. Open the flyout via + button.
2. **Expected:** up to 10 recently opened projects shown with relative timestamps.
3. Click a recent — **Expected:** new tab opens for that project.
4. Press arrow-down/up to navigate, Enter to open — **Expected:** keyboard nav works.

### TC-7: Open Project flyout — browse
1. Open the flyout; click "Browse…".
2. **Expected:** native folder-picker dialog opens; selecting a folder opens a new tab.

### TC-8: Open Project flyout — drag-and-drop
1. Drag a folder from Windows Explorer onto the flyout drop zone.
2. **Expected:** new tab opens for the dragged folder.

### TC-9: SessionView tab switch preserves state
1. Open two sessions; generate a turn in session A (scroll down).
2. Switch to session B; switch back to session A.
3. **Expected:** scroll position, turn history, and any in-progress tool cards are preserved.

### TC-10: Blocker badge
1. Trigger a UI blocker in an active session.
2. Switch to another tab.
3. **Expected:** the waiting session's tab shows an orange badge with the blocker count.

## Edge Cases
- Tab display name truncated at 24 chars — verify ellipsis shown for long paths.
- Flyout position clamped at right viewport edge — verify no horizontal scroll overflow.
- Escape closes flyout without opening a project.
- Ctrl+T keyboard shortcut does NOT fire inside the rename input or the composer textarea.
