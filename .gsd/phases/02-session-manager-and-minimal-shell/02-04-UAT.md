# S04: IPC Bridge and Preload — UAT

**Milestone:** M002
**Written:** 2026-07-20

## UAT Type

- UAT mode: runtime-executable
- Why this mode is sufficient: S04 delivers IPC plumbing and a preload bridge. The observable acceptance criteria are covered by the 54-test Vitest suite (no renderer rendering needed). Integration properties (contextIsolation, window.gsd shape, unsubscribe functions) are verified in the preload unit tests. A browser-executable test of the full chat round-trip belongs to S05/S06.

## Preconditions

- `pnpm install` has been run in D:/Projects/gsd-tau
- Node ≥ 20, pnpm ≥ 9

## Smoke Test

Run `pnpm test` — all 154 tests must pass (7 files, ≤ 2s).

## Test Cases

### 1. IPC handlers registered and dispatch correctly

1. Run `pnpm test -- ipc/handlers`
2. **Expected:** 23 tests pass; ipcMain.handle is called for openProject, prompt, abort, getState; session events fan out via webContents.send('session:event', …); state changes fan out via webContents.send('session:state-change', …)

### 2. Preload bridge exposes window.gsd cleanly

1. Run `pnpm test -- preload`
2. **Expected:** 31 tests pass; contextBridge.exposeInMainWorld is called exactly once with 'gsd' and an object containing openProject, prompt, abort, getState, onEvent, onStateChange; onEvent and onStateChange each return an unsubscribe function; no raw ipcRenderer handle is present in the exposed object

### 3. Isolation guards hold

1. Inspect preload test assertions for window.require and window.process
2. **Expected:** Tests confirm these are not leaked; contextIsolation is enforced by Electron's security model at runtime

### 4. Full suite baseline

1. Run `pnpm test`
2. **Expected:** 154/154 pass (7 files) with no skipped or failing tests

## Edge Cases

### Duplicate onEvent subscriptions

1. In preload test: call onEvent twice for the same sessionId, then call both unsubscribes
2. **Expected:** Each returns an independent unsubscribe; calling one does not remove the other listener

### abort on non-existent session

1. In handlers test: invoke abort with an unknown sessionId
2. **Expected:** Handler rejects or returns gracefully without crashing the main process

## Failure Signals

- Any test file red in `pnpm test` output
- `contextBridge.exposeInMainWorld` call count ≠ 1 in preload tests
- `window.require` or `window.process` accessible in DevTools (contextIsolation misconfigured)

## Not Proven By This UAT

- Live Electron window rendering (S05)
- End-to-end pi RPC round-trip through the renderer (S05/S06)
- 10-consecutive Playwright smoke run (S06)
- Shutdown pi child-process cleanup (S06)

## Notes for Tester

The preload module cannot fully simulate Electron's contextIsolation in a Node/jsdom environment. The unit tests verify the contextBridge call shape and the API surface; true isolation (window.require === undefined at runtime) must be spot-checked in DevTools after `pnpm dev` is wired up in S05.
